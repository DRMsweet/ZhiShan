# 至善中学网页解密 · 《蓬莱一中：夜晚的脚步声》

一个纯前端灵异校园解密游戏（仿《404工位消失事件》架构），零依赖、无框架、无后端，
解压即玩，也可免费部署到 GitHub Pages。

## 🎮 剧情简介

你是蓬莱一中高二（3）班学生**姜**。上周因为"熄灯前没跑起来"，被级部主任**李志胜**赶回家反思一周。
返校后你发现学校变了：同学被扣分后一个个"转学"、宿舍夜里响起没有主人的脚步声、厕所隔间自己冲水、
校长寇润平二十年的"升学率神话"……

调查后你发现：**扣分不是惩罚，是登记；《常规》不是检讨，是祭文**。
1998 年旧教学楼（城隍庙旧址）封闭后，寇润平用扣分制度收集学生的名字喂养"那个东西"，
换来蓬莱一中二十年的升学奇迹。

## 🔑 剧情关键设定（改写时不要破坏）

- **铁律一**：每个密码门的答案，必须出现在编号**更小**的页面里（顺序推进）
- **铁律二**：扣分 = 登记名字；常规 = 祭文/名单；这是全部灵异设定的地基
- **脚步声规则**：李志胜=皮鞋、邢波=布鞋、任党林=无声、王晓=咳嗽；第四个脚步声不穿鞋，只停在"被扣过分的门口"
- **护身符设定**：于的灵梦魔理沙挂件 = 护身符，被没收后于才被缠上
- **"跑起来"意象**：开篇是压迫（李志胜逼跑），结局是反抗（"这一次，我跑起来了"）

## ✏️ 如何修改

1. **换主角**：`index.html` 开场白 + `student.html` 档案 + `final.html` 署名
2. **改密码**：`pages/locker.html` 的 `CORRECT_PWD`、`pages/forum.html` 的 `CORRECT_USER/PASS`，同时改线索页
3. **加页面/关键词**：复制关卡页到 `pages/`，在 `desk.html` 的 `FILE_DATABASE` 加映射
4. **换校名**：页面中"蓬莱一中"全局替换（游戏标题在 `index.html` 的 `<title>` 与 badge）

## 🌐 部署到 GitHub Pages（免费）

1. 新建 GitHub 仓库，上传全部文件
2. 仓库 Settings → Pages → Source 选 `main` 分支根目录
3. 访问 `https://你的用户名.github.io/仓库名/`

## 🔧 进阶改造建议

- 进度存档：`localStorage` 记录已解锁页面
- 数据驱动：线索内容抽成 `data.js`（JSON），JS 渲染
- 搜索模糊匹配：`keyword.includes(query)` 降低难度
- 埋点统计：搜索词 POST 到 Google Apps Script
- 音效：脚步声 Audio 循环、解锁音效（本作特别适合！）
