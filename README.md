# 至善中学网页解密 · 《蓬莱一中：夜晚的脚步声》

## 🎮 剧情简介

你是蓬莱一中高二（3）班学生**姜**。上周因为"回宿舍路上没跑起来"，被级部主任**李志胜**赶回家反思一周。
返校后你发现学校变了：同学被扣分后一个个"转学"、宿舍夜里响起没有主人的脚步声、厕所隔间自己冲水、
校长寇润平二十年的"升学率神话"……

调查后你发现：**扣分不是惩罚，是登记；《常规》不是检讨，是祭文**。
1998 年旧教学楼（城隍庙旧址）封闭后，寇润平用扣分制度收集学生的名字喂养"那个东西"，
换来蓬莱一中二十年的升学奇迹。你要集齐证据，赶在"名单"记住你的名字之前，把真相带出去。

## 🔑 剧情关键设定（改写时不要破坏）

- **铁律一**：密码门答案必须出现在编号更小的页面；证据页必须出现在 final 之前
- **铁律二**：扣分=登记名字；常规=祭文/点名册；这是全部灵异设定的地基
- **脚步声规则**：李志胜=皮鞋、邢波=布鞋、任党林=无声、王晓=咳嗽；第四个不穿鞋，只停在被扣过分的门口
- **护身符设定**：于的灵梦魔理沙挂件=护身符，被没收后于才被缠上
- **"跑起来"意象**：开篇是压迫，终章是反抗
- **常规第四十七条**：夜间听到有人喊自己的名字，不得应答、不得开门、不得开灯（dorm 抉择的核心规则）

## ✏️ 如何修改

1. **换主角**：`index.html` 开场白 + `student.html` 档案 + `final.html` 署名
2. **改密码**：`pages/locker.html` 的 `CORRECT_PWD`、`pages/forum.html` 的 `CORRECT_USER/PASS`，同时改线索页
3. **加页面/关键词**：复制关卡页到 `pages/`，在 `desk.html` 的 `FILE_DATABASE` 加映射，进度徽章改成对应数字
4. **加坏结局**：参考 `badend1.html`，用 `location.href` 跳转
5. **证据系统**：新证据页加 `localStorage.setItem('zs_clue_xxx','1')`，在 final.html 的 CLUES 数组注册
